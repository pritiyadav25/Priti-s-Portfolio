## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/pritiyadav25/Priti-s-Portfolio.git
cd Priti-s-Portfolio
```

### 2. Setup Backend
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### 3. Setup Frontend
```bash
cd ../frontend
npm install
npm run dev
```

The frontend will run on `http://localhost:5173` and backend API on `http://localhost:5000`.
